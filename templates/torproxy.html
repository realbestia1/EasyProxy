The exit relay is pinned automatically, so the egress IP never changes on its own. Request new IP switches to a different relay and pins that one. If the pinned relay goes offline, use Request new IP to recover.
Pick an exit country from the list loaded live from Tor — only countries currently running exit relays are shown. Selecting a country pins the relay Tor picks there: the egress IP stays fixed until Request new IP, which picks another relay in the same country. Automatic (no pin) releases the selection. If the new selection cannot be reached, the previous one is restored automatically.


    

    

        
Use it in EasyProxy

        
Paste this URL into Global Proxies, a Transport Route or an extractor proxy:

        socks5h://127.0.0.1:9050
        
Tor is TCP-only. Streaming may be slow; use it for privacy/specific routes, not as default for all traffic.
